# Sigma Detection Rule Practice

## Objective
Learn the structure of Sigma-style detection rules: title, log source, detection logic, and level.

## Files
- `rules/repeated_failed_logons.yml`
- `rules/suspicious_powershell_example.yml`
- `test-cases.md`

## Important
These are educational examples. Sigma rule field names and backend behavior depend on the log source and conversion pipeline. Validate rules against the actual schema and test environment before operational use.
